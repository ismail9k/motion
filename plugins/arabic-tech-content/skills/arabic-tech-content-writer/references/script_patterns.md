# Script Patterns for Arabic Tech Content

## Script Structure

Every script should follow this three-part structure:

### 1. Hook/Intro (أول 5-10 ثواني)
- Start with a provocative question or surprising statement
- Create immediate curiosity
- Create tension, consequence, or an unanswered question
- Examples:
  - "عارف إن ممكن أخترقك بالصورة دي؟"
  - "لو معاك آيفون… إنت في خطر حقيقي!"
  - "يا هل ChatGPT بيجمع معلوماتنا؟"
  - "أنا عملت أبلكيشن باستخدام الـAI... وبدأ يدخل لي آلاف الدولارات"

### Hook Strength Test
A strong hook should pass at least 2 of these checks:
- It names a specific risk, benefit, mistake, or surprise.
- It makes the viewer ask "إزاي؟" or "ليه؟"
- It feels urgent without sounding fake.
- It could not be reused unchanged for any random tech topic.
- It gives the viewer a reason to keep watching before the first pause.

### 2. Main Content (الجسم الأساسي)
- Break down complex technical concepts into simple, relatable explanations
- Use storytelling and real examples
- Include specific technical details when relevant
- Make analogies to everyday life
- Build suspense and maintain engagement
- Add pattern interrupts so the script does not become one long explanation

**Key techniques:**
- Use "يعني" to simplify explanations
- Include rhetorical questions: "عارف ليه؟"
- Add personal experience: "من تجربتي..."
- Use dots (...) for dramatic pauses
- Include humor occasionally with emojis (😅, 😂, 😏, 😎)

### Retention Loop
Open a loop early and close it near the end.

Examples:
- "بس في تفصيلة واحدة هي اللي مخلية الموضوع خطير..."
- "والجزء اللي ناس كتير مش واخدة بالها منه؟"
- "استنى للآخر عشان النقطة دي ممكن تغير رأيك."

Use one loop only. Too many loops feel manipulative.

### Pattern Interrupts
Every 15-25 seconds, break the rhythm with one of these:
- A contradiction: "بس العكس هو اللي حصل."
- A quick example: "يعني تخيل شركة عندها..."
- A rhetorical question: "طب ليه ده مهم؟"
- A short punchline: "وده طبعًا مكانتش الخطة العبقرية اللي كنا متخيلينها."
- A visual moment: "حط الصورة دي في دماغك..."

### 3. Call-to-Action/Conclusion
- End with a question to the audience
- Encourage engagement: "عرفوني رأيكم..."
- Sometimes include a humorous twist
- Close with "سلام" or "سلام ✌️"

### Strong CTA Patterns
- Choice: "تختار أنهي واحد؟"
- Confession: "عملت الغلطة دي قبل كده؟"
- Challenge: "جربها وقولي النتيجة."
- Debate: "تتفق معايا ولا شايف العكس؟"
- Experience: "مين استخدم الأداة دي فعليًا؟"

Avoid generic endings like "قولولي رأيكم في الكومنتات" unless paired with a specific question.

## Platform Playbooks

### Instagram Reels
- Style: conversational, polished, creator-led
- Best length: 45-75 seconds
- Hook: strong but not too aggressive
- Rhythm: short lines with clear visual beats
- CTA: comment-focused and easy to answer
- Works well for: AI tools, coding workflows, comparisons, personal experience

### TikTok
- Style: faster, more provocative, trend-aware
- Best length: 30-60 seconds
- Hook: surprising, blunt, or controversial
- Rhythm: quick cuts, sharper transitions, more interruptions
- CTA: debate, confession, or challenge
- Works well for: myths, warnings, hot takes, mistakes, surprising facts

### YouTube Shorts
- Style: clear, structured, payoff-driven
- Best length: 45-90 seconds
- Hook: curiosity plus clear topic
- Rhythm: setup, explanation, payoff
- CTA: subscribe/follow only when natural; prefer topic question
- Works well for: explainers, security stories, product launches, concise tutorials

### LinkedIn
- Style: professional, practical, credibility-led
- Best length: 60-120 seconds
- Hook: insight, market shift, productivity gain, or business risk
- Rhythm: fewer jokes, more evidence and implications
- CTA: thoughtful professional question
- Works well for: AI impact, developer productivity, security risk, leadership takes

## Variant Angles

Use these when the user asks for multiple versions.

### Urgent Warning
- Start with risk or consequence.
- Best for privacy, cybersecurity, bad practices, or deadlines.
- Example hook shape: "لو بتستخدم [tool] بالطريقة دي... وقف دلوقتي."

### Contrarian Opinion
- Start by challenging a popular belief.
- Best for AI hype, programming myths, career advice, tool debates.
- Example hook shape: "الناس كلها بتقول [belief]... بس أنا شايف العكس."

### Practical Tutorial
- Start with the result.
- Best for workflows, tools, prompts, debugging, automation.
- Example hook shape: "في أقل من دقيقة، هتعمل [result] باستخدام [tool]."

### Story/News
- Start with an event, company, founder, or incident.
- Best for launches, vulnerabilities, research, market shifts.
- Example hook shape: "من كام يوم، [company/person] عملت حاجة غريبة..."

### Funny/Relatable
- Start with a common frustration.
- Best for developer humor, AI mistakes, workflow pain.
- Example hook shape: "لو قضيت 3 ساعات بتصلح bug وفي الآخر كان typo..."

### Comparison
- Start with a choice.
- Best for model/tool/framework comparisons.
- Example hook shape: "تستخدم [A] ولا [B]؟ الإجابة مش زي ما الناس فاكرة."

## Tone & Voice Patterns

### Educational but Conversational
- Don't lecture; have a conversation
- Use "إحنا" instead of "نحن"
- Mix Modern Standard Arabic with Egyptian dialect naturally
- Be direct and authentic

### Technical Accuracy with Simplicity
- Explain technical terms in simple language
- Use analogies: "زي العربية بالضبط"
- Don't oversimplify, but make it accessible

### Engaging Storytelling
- Start with real incidents or news
- Build narrative tension
- Include specific numbers and facts
- Reference real people/companies

### Viral Without Clickbait
- Drama is allowed; fake certainty is not.
- Make the hook intense, then make the explanation honest.
- If a topic has nuance, say it clearly.
- Do not invent numbers, claims, vulnerabilities, product features, or release dates.
- When facts are missing, write around the known idea or ask for source material.

## Description Writing

### Structure
1. **Hook question or statement** (1-2 lines)
2. **Key insight or revelation** (2-3 lines)
3. **What the video covers** (optional, 2-3 lines)
4. **Engagement prompt** (1 line)

### Tone
- Slightly more formal than the script
- Still conversational and engaging
- Use emojis strategically (🔥, 💡, 🚨, 👇, 🤔)

## Hashtags Strategy

### Mix Arabic and English
- Use both Arabic and English hashtags
- Include brand names as hashtags (#ChatGPT, #Claude, #Gemini)
- Add topic-specific tags (#ذكاء_اصطناعي, #AI, #البرمجة)
- Include trend-relevant tags when applicable

### Typical Range
- 5-15 hashtags per post
- Balance between broad and specific tags

## Examples of Effective Patterns

### Pattern 1: News-Based Content
1. Start with recent announcement/incident
2. Explain what happened
3. Break down technical details
4. Discuss implications
5. Personal take or future outlook

### Pattern 2: Educational Explainer
1. Hook with common misconception or question
2. Tell the origin story or context
3. Explain how it actually works
4. Use analogies and examples
5. Practical takeaway

### Pattern 3: Comparative Analysis
1. Introduce multiple options/tools
2. Share personal experience with each
3. Compare strengths and weaknesses
4. Give recommendations based on use case
5. Ask audience for their preference

### Pattern 4: Security Warning
1. Urgent hook about vulnerability/risk
2. Explain the technical threat
3. Show real-world impact
4. Provide actionable solution
5. Emphasize importance of action

### Pattern 5: Myth-Busting
1. Name the popular belief
2. Challenge it with a sharp line
3. Explain the real technical reason
4. Show the edge case or nuance
5. Ask viewers what they thought before

### Pattern 6: Workflow/Tutorial
1. Start with the result or time saved
2. Show the painful old way
3. Introduce the tool/workflow
4. Give 2-4 clear steps
5. End with a try-it challenge
