# 9k HyperFrames registry

Reusable pieces of the 9k edit, so every short looks and moves the same. Generated by `node registry/build.mjs`
from `src/`: edit `src/items.mjs` (a block) or `src/shared.mjs` (tokens, fonts, motion, the block shell), then
rebuild. Never hand-edit `blocks/` or `components/`.

## See them

`node registry/build.mjs` also writes `registry/preview/`, a gallery project that plays every block with its default
values, labelled, in the split layout. Open it in HyperFrames Studio to watch, scrub, and try values in each block's
variables panel:

```bash
cd registry/preview && npx hyperframes preview
```

It is regenerated on every build (and gitignored), so changes there are thrown away: change `src/`, rebuild, and Studio
reloads.

## Use it in a HyperFrames project

Point the project at this registry in `hyperframes.json`:

```json
{ "registry": "https://raw.githubusercontent.com/ismail9k/motion/main/registry" }
```

```bash
npx hyperframes add 9k-band          # a block → compositions/9k-band.html (+ 9k-tokens: fonts → assets/fonts/)
npx hyperframes add 9k-split-layout  # a component → compositions/components/9k-split-layout.html
npx hyperframes add 9k               # every block tagged 9k
```

Until the registry is on GitHub, install from this folder instead. It does what `add` does, and keeps files you
edited after installing (`--force` replaces them):

```bash
node ~/ismail9k/motion/registry/install.mjs <project>            # everything
node ~/ismail9k/motion/registry/install.mjs <project> 9k-band    # one item (+ 9k-tokens)
```

After changing `src/` and running `build.mjs`, run `install.mjs` again in each film to update it.

Wire a block with a host whose `data-composition-id` is the block name, and set its text and timing with
`data-variable-values`. The same block can appear any number of times, each with its own values:

```html
<div id="band-proof" data-composition-id="9k-band" data-composition-src="compositions/9k-band.html"
  data-start="15.9" data-duration="1.2" data-track-index="3" data-width="1080" data-height="608"
  data-variable-values='{"text":"مثبت رياضيًا","underline":"رياضيًا"}'
  style="position:absolute;left:0;top:0;width:1080px;height:608px"></div>
```

Blocks are silent: put SFX on the host, 8–14 dB under his voice (climax ≈ 6 dB under). Suggested hits: hook stamp →
thud, band → needle + bass, number roll → ticks then a ding on landing, verdict → pop per side, kicker → soft click.

## Components

- **`9k-tokens`**: The 9k design tokens as CSS custom properties plus the IBM Plex Sans Arabic / Sans / Mono font faces (OFL, shipped as assets). Every 9k block depends on it.
- **`9k-split-layout`**: The host layout for reaction shorts: a 1080×608 top panel for the reference clip or a picture scene, the talking head below it, a seam and shade where they meet, and alternating punch-in framing for jump cuts.

## Blocks

### `9k-captions` (1080×1920, 8 s)

Arabic word-by-word captions (≤ 4 words, orange keyword pill) with one English line per sentence, in the 9k style. Cues are [start, end, "arabic with *keyword", "english"].

| Variable | Type | What | Default |
|---|---|---|---|
| `cues` | string | Cues JSON: [[s, e, "arabic *kw a~b", "english"], …] | `[[0.2,3.4,"بس هو أنهي *AI بالظبط؟","B…` |
| `top` | number | Stack top (px) | `630` |
| `arSize` | number | Arabic size (px) | `60` |
| `enSize` | number | English size (px) | `34` |
| `english` | boolean | Show English line | `true` |

### `9k-hook-stamp` (1080×1920, 3.6 s)

The opening stamp: a typed headline in an orange-bordered pill that lands with a heavy spring, and an optional black-on-orange sub line typed after it.

| Variable | Type | What | Default |
|---|---|---|---|
| `line` | string | Headline | `أنهي AI بالظبط؟` |
| `sub` | string | Sub line (empty = none) | `` |
| `top` | number | Top (px) | `280` |
| `cps` | number | Typing speed (chars/s) | `16` |

### `9k-band` (1080×608, 1.2 s)

The once-per-film climax band: a full-width brand-green strip that snaps open with one big line, and an orange underline drawing under the key word. Hold ≤ 1.2 s.

| Variable | Type | What | Default |
|---|---|---|---|
| `text` | string | Line | `مثبت رياضيًا` |
| `underline` | string | Word to underline (must be in the line) | `رياضيًا` |
| `top` | number | Top (px) | `214` |
| `size` | number | Text size (px) | `84` |

### `9k-kicker` (1080×608, 3 s)

A panel title: a typed Latin term (the field or product name) with its Arabic name under it, on the dark 9k panel. Use at the start of an explainer block.

| Variable | Type | What | Default |
|---|---|---|---|
| `title` | string | Title (Latin) | `Operations Research` |
| `sub` | string | Arabic name | `بحوث العمليات` |
| `panel` | boolean | Dark 9k panel behind | `true` |
| `top` | number | Top (px) | `24` |

### `9k-number-roll` (1080×608, 4.6 s)

A big number that rolls into place digit by digit (odometer) in a pill, with an orange label: for the one stat a sentence turns on.

| Variable | Type | What | Default |
|---|---|---|---|
| `value` | string | Value (digits and commas) | `27,000,000,000,000,000` |
| `label` | string | Label | `احتمال حل` |
| `at` | number | Pill lands at (s) | `0.6` |
| `roll` | number | Roll length (s) | `3.4` |
| `top` | number | Top (px) | `392` |
| `panel` | boolean | Dark 9k panel behind | `false` |

### `9k-verdict` (1080×608, 4 s)

Two answers side by side: a chat bubble with "?" (one suggests) against a green equation card with ✓ (the other proves). Each side pops in on its word.

| Variable | Type | What | Default |
|---|---|---|---|
| `rightLabel` | string | Right label (the guess) | `بيقترح حل` |
| `leftLabel` | string | Left label (the proof) | `مثبت رياضيًا` |
| `code` | string | Equation line | `min f(x)` |
| `note` | string | Equation note | `gap = 0` |
| `rightAt` | number | Right pops at (s) | `0.2` |
| `leftAt` | number | Left pops at (s) | `1.6` |
| `panel` | boolean | Dark 9k panel behind | `true` |
